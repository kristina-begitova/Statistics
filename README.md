# Прикладная статистика: проверка гипотез, доверительные интервалы и анализ исследований

Два блока работ по прикладной статистике на данных RLMS-HSE и собственных опросах. Стек: R (haven, ggplot2).

## Доверительные интервалы и проверка гипотез

**Гендерный разрыв в зарплатах.** Данные: RLMS 2019, сфера образования, Москва (n = 30: 24 женщины, 6 мужчин). Построены доверительные интервалы средней зарплаты по полу (90/95/99 %) и интервал для разности средних независимых выборок с разными дисперсиями; t-тест на равенство средних. Результат: t = 0.51 — H₀ не отвергается, статистически значимой разницы в зарплатах нет. Интервалы у мужчин заметно шире из-за малого размера подвыборки (n = 6).

**Интернет среди пожилых (60+).** Данные: собственный опрос, n = 88. Через `power.prop.test` обоснован минимально необходимый размер выборки (77). Проверка гипотезы о доле пользователей: z = 6.18, H₀ (p = 0.5) отвергается на любом уровне. Результат: интернетом пользуются 83 % опрошенных — вопреки стереотипу о низкой цифровой грамотности пожилых.

**Семья и работа.** Данные: RLMS 2020, возраст 25–45. Сравнение доли трудоустроенных среди состоящих (p₁ = 0.77) и не состоящих (p₂ = 0.74) в браке: доверительные интервалы для разности долей, Z-тест на равенство долей. По всей выборке Z = 1.80 — различие значимо только на уровне 10 %. Ключевой результат: при разбивке по полу эффект противоположный (у мужчин выше занятость среди женатых, у женщин — среди незамужних), поэтому в агрегате эффекты гасят друг друга и различие «исчезает».

**До и после пандемии.** Данные: RLMS, волны 2017 и 2022, связанные выборки по ID респондента; отобраны люди с исходно повышенным ИМТ. Проверка гипотезы о среднем изменении ИМТ (H₀: μ = 0). Результат: ИМТ в среднем значимо снизился — то есть по этому показателю здоровье группы после пандемии улучшилось; у женщин изменения выражены сильнее, чем у мужчин.

## Анализ исследований и дизайн опросов

**Критический разбор публикации** (цифровые медиа и интеллект детей, *Scientific Reports*, 2022, выборка ABCD, ~5000 детей). Разбор метода выборки (стратифицированная случайная), источников смещения (response bias, non-response bias, эффект пандемии) и сравнение со альтернативными методами. Вывод: стратифицированная выборка здесь оправданнее квотной, но точность повысил бы учёт жанра игр и объективный замер экранного времени.

**Тренды на данных RLMS.** Разбор устройства выборки RLMS (многоступенчатая стратифицированная вероятностная) и проектирование исследования: постановка вопроса о динамике психического здоровья, обоснованное разбиение на возрастные группы и учёт гендерного разреза.

**Собственный опрос тремя методами.** Данные собраны случайной, удобной и квотной выборками (тема: желаемое число детей у поколения Z). Тест хи-квадрат на связь между числом детей в родительской семье и желаемым числом детей; Z-тест на равенство желаемого числа детей у мужчин и женщин (Z = 0.53, p = 0.60 — различий нет). Показано, как метод формирования выборки меняет результат.

**Разработка фальсифицированного исследования** — учебное упражнение на распознавание манипуляций: предвзятые выборки, наводящие вопросы, подмена результатов.
